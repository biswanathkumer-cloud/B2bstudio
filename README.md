StudioPrint Fresh — browser-only photo editor

1. Extract this ZIP.
2. Open index.html in Chrome or Microsoft Edge.
3. Click Add photos.
4. Select a thumbnail to edit; use Delete selected or the × on its thumbnail.
5. Changes to brightness/contrast/saturation/warmth preview immediately. Use crop: choose preset, Draw crop, drag on the image, Apply crop.
6. The print preview is fixed in the right sidebar. Choose paper, size, copies, queue and margins. Click Update print preview.
7. Click Print and choose Actual size / 100% in the browser print dialog.

No server, Python, installation, account or upload. Images stay in this browser tab's memory. This is a local browser editor, not a full Photoshop clone. Background replacement is a simple near-white color key, not AI segmentation. Browser print accuracy depends on printer driver settings. Presets are editable convenience sizes; verify current official PAN/NSDL/UTI requirements before submission.
